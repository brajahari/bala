Vedabase: how to use

Back to main page

1. Hear / read

  • Choose a box. You may edit it to any Vedabase format, e.g. bg/2, bg/2/1.
  • Press / to hear/read.

2. Bookmarks

  • Box values are auto-saved, including % position within the page (e.g. bg/10 35%).

3. + and −

  • Edit the selected box to the next / previous page.
  • If it's incorrect/not loading, just edit the box manually.

4. ↗ opens the page on vedabase.io instead.
